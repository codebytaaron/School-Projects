# Study Planner

A Python program that helps students organize homework, projects, and other school assignments.

## Features

- Add assignments
- Add a subject for each task
- Choose a priority
- View all tasks
- Mark work as complete
- See unfinished assignments
- Search tasks by subject
- Track completion progress
- Remove tasks

## Python Concepts Used

- Variables
- Lists
- Functions
- While loops
- For loops
- If statements
- User input
- Basic math
