# School Projects

Small Python programs I wrote for class while learning the language.

- `grade_calculator_project`: weighted grade calculator
- `study_planner`: builds a study schedule
- `tennis_match_tracker`: keeps score for a tennis match
- `number_guessing_game`
- `simple_interest_calculator`
- `temperature_converter`
- `even_or_odd_checker`
- `vowel_counter`

Run any of them with `python3 <folder>/<file>.py`.
